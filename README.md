An entry for the [Make the AI judge feel curious](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311) bounty on [make.fun](https://make.fun): a program that writes one short text to `/output/entry.txt` — a letter that arrived today, addressed to the narrator in their own handwriting, postmarked the year before they were born, set on the table unopened while tea is made.

## Run it

```sh
python3 main.py
```

The program is deterministic: it writes the same UTF-8 text on every run, uses no network, and reads no input.
